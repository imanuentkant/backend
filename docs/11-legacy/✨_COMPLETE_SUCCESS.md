## 🚀 MULTI-NODE QUICK START

Sau khi push, để chạy multi-node:

```bash
# Install PM2
npm install -g pm2

# Start cluster (tự động detect CPU cores)
pm2 start ecosystem.config.js

# Check status
pm2 status
```

**Kết quả**: 4-8 nodes chạy song song! 🚀

### Or với Docker:
```bash
# Scale to 5 nodes
docker-compose up --scale backend=5 -d

# Check
docker-compose ps
```

### Or với Kubernetes:
```bash
# Deploy (HPA tự động scale 3-10 nodes)
kubectl apply -f k8s/

# Check pods
kubectl get pods
```
